# K230 数字手势识别 Demo
> 项目目标：摄像头实时识别0~5数字手势，在屏幕上输出识别结果
> 定位：零基础入门项目，不用深挖YOLO模型底层原理，优先学会工具调用、跑通视觉项目，产出可演示效果

## 📋 项目介绍
本项目基于YOLO模型，在K230开发板上实现手势识别。
对着摄像头比出 0、1、2、3、4、5 的手势，开发板屏幕就会绘制检测框并输出识别结果。
> 现阶段不用理解神经网络、卷积、NMS等底层原理，先学习AI工具的使用流程。

### 2. 基础概念
- 固件：K230板子的系统，类似电脑Windows
- 模型文件：我们训练好的YOLO手势识别文件，后缀 `.kmodel`，是AI的“大脑”
- 置信度：模型判断“这个目标是不是手势”的把握程度，0~1之间，数字越大越确定
- ROI：摄像头画面区域（暂时不用深究）

## 🛠️ 环境安装步骤（跟着一步步点）
### 步骤1：安装 CanMV IDE（K230专用软件）
1. 打开官网下载：https://canmv.io/#/download
2. 根据你的电脑系统（Windows / Mac）下载对应安装包
3. 安装：一路下一步，**不要修改中文路径**（文件夹名字不要带中文、空格！）
> ⚠️ 重要避坑：软件、项目路径全部用英文！中文路径会导致程序报错！

### 步骤2：给K230烧录固件
1. 用Type-C线，把K230开发板连接电脑
2. 打开CanMV IDE，右上角选择对应开发板型号（CanMV K230）
3. 点击【烧录固件】，选择官方最新CanMV固件，等待烧录完成
4. 烧录成功后，IDE右下角提示连接成功

### 步骤3：获取本项目代码 & 模型
1. 把本demo文件夹下载到电脑（路径英文，不要中文）
2. 里面包含：
   - `main.py`：主运行代码
   - `gesture.kmodel`：YOLO手势识别模型（已经训练好，直接用）
   - `labels.txt`：标签文件，对应0,1,2,3,4,5
3. 在CanMV IDE打开 `main.py`

## 🚀 运行项目
1. 确认开发板和电脑连接正常
2. 在CanMV IDE打开代码，点击右上角【运行】▶️
3. 板子摄像头亮起，对着摄像头比手势
4. 屏幕上会画出框，并且显示识别出来的数字

## ⚙️ 简单可以修改的地方（新手尝试）
> 改这里，感受自己在控制AI程序，不用碰模型训练！
1. `conf_threshold = 0.5` 置信度阈值
   - 调大比如0.7：识别更严格，不容易误识别，但是不容易识别出手势
   - 调小比如0.3：更容易识别，但是更容易认错
2. 屏幕文字：修改 `print()` 和屏幕显示文字，改成你想要的提示

## ⚠️ 高频踩坑&注意事项（一定要看！）
1. ❌ 路径不要中文！文件夹、文件名全部英文，中文会直接报错
2. ❌ 光线不能太暗，光线差模型识别会很不准
3. ❌ 手势尽量正对摄像头，背景不要太杂乱
4. ❌ 不要热插拔、不要在烧录的时候拔掉数据线，容易损坏板子
5. 如果识别一直乱跳：调高置信度阈值，或者调整光线
6. 模型文件 `gesture.kmodel` 必须和代码一起上传到开发板，缺一不可！
