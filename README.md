# k230-ai-vision-lab
华侨大学 AIoT 社团 AI视觉与算法组 K230 边缘视觉开源仓库

## 📌 仓库简介
本仓库汇集基于 K230（CanMV）平台的嵌入式AI视觉演示项目与实验例程。
项目设计思路由浅入深，优先聚焦工程实践落地，使用者可先掌握模型调用、项目部署流程，实现可视化效果，后续再深入算法底层原理。

## 🧰 硬件与开发环境
- 主控硬件：CanMV K230 开发板
- 配套配件：Type-C 数据线
- 开发工具：CanMV IDE

## 📂 Demo 目录
- `k230-gesture-number-demo`：数字手势识别Demo（入门示例）
  实现 0~5 数字手势实时检测，摄像头采集画面并在屏幕输出识别结果，适合作为上手实践项目。

## 📖 学习与实践路线
1. 完成手势识别Demo部署，熟悉开发环境、固件烧录、模型加载整套工作流
2. 掌握基础 Python 语法，读懂推理业务代码
3. 自主调试程序参数，例如调整置信度阈值、自定义画面输出信息
4. 进阶方向：数据集标注、训练自定义目标检测模型

## 🤝 贡献规范
社团成员贡献流程：Fork 仓库 → 创建独立分支 → 完成开发与自测 → 提交 Pull Request
所有使用者可查阅各Demo目录下的文档，按照指引复现项目。
